# Playwright Automation Project – Daraz.pk

## Project Overview

This project contains automated UI tests for the Daraz.pk e-commerce website using Playwright. The tests cover product searching, filtering, product validation, and checking free shipping availability.

The project follows the Page Object Model (POM) to keep the automation code organized and reusable.

## Learning Objectives

- Learn the basics of Playwright automation.
- Automate real-world e-commerce workflows.
- Perform product search and filtering.
- Write assertions for UI validation.
- Use the Page Object Model (POM).
- Organize Playwright tests using a maintainable structure.

## Tasks Completed

1. Set up a Playwright project using Node.js.
2. Navigated to the Daraz.pk homepage.
3. Searched for the "Electronics" category.
4. Applied a brand filter.
5. Applied a price filter from 500 to 5000 PKR.
6. Counted and validated the displayed products.
7. Opened a product details page.
8. Checked the availability of the "Free Shipping" indicator.
9. Implemented the Page Object Model.
10. Added Playwright test configuration and documentation.
